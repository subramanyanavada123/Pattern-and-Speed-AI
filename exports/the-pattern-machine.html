Act II — The one move

Act II

Pattern + senses + a brain + hands + a loop = agent.

That's it. No GPU. No model training. Mostly plumbing.

Act II · The recipe

Four things you bolt onto a pattern

👀+ senses

Perceive

Read the signals you already generate.

🧠+ a brain

Decide

Given context, pick one useful move — or none.

✋+ hands

Act

A few small, well-labelled tools. Nothing else.

🔁+ a loop

Learn

Did it work? Feed the outcome back.

The "brain" is one model call. The other three are code you could write today.

Act II · The shape of every agent

Perceive → decide → act → observe → repeat

01PerceiveRead state: sensors, calendar, the last result.
02DecidePick the next action. Rule, or model call.
03ActFire a tool. The world changed.
04ObserveTake in the result. Win? Error? New info?
05CheckDone — or loop with what you now know.

A thermostat, a chess engine, a coding assistant, a traffic light: all run this. What differs is how "decide" works and how tightly the loop is scripted.

Act II · The detailed reason

Why the "decide" step is a model, not an if

Rules work when…

Every case was foreseen

if days_since > 3: nudge(). Fine for a week. Then you tune it out — a generic nag isn't a pattern-break, it's noise.

A model works when…

The case wasn't foreseen

It's seen millions of traces of people planning, nudging, recovering. It produces a plausible next move for situations nobody enumerated.

  • Generalization — handles the unseen Tuesday the way a classifier handles an unseen photo.
  • Language is the interface — goals, context, tool calls are all just text it continues.
  • Steer with examples, not a retrain. Change the prompt, change the behavior.

Build 02 · Never-Forget Agent

"You always forget Mom's birthday" — solved in 20 lines

  • Sense: contacts + a "close people" list you set once.
  • Brain: given the person and your past messages to them, draft something that sounds like you, not a card.
  • Hands: draft_message(), suggest_gift(budget), add_calendar_reminder().
  • Rail: never sends automatically. It stages; you approve.

The one irreversible act — hitting send to a human — stays with you. Always.

# the whole agent, basically
for p in close_people:
    if days_until(p.birthday) == 3:
        draft = llm(
          "Write a warm birthday text in MY voice",
          history = messages_with(p),
          person  = p,
        )
        gift = llm("3 gift ideas", person=p, budget=1500)
        # stage for approval — never auto-send
        inbox.stage(draft, gift)

City agent 02 · Adaptive traffic signals

Green lights that watch the queue

  • Pattern: traffic flow has strong daily & weekly rhythm, plus shocks (a match, a crash).
  • Senses: inductive loops in the road, cameras, connected-vehicle pings.
  • Decide: extend this green, hold that red, offset the next junction so a "green wave" forms.
  • Rails: minimum green time, pedestrian phases guaranteed, emergency-vehicle pre-emption overrides everything.
Why it's an agent, not a timer

It observes, then adapts

A fixed-timer light is deterministic and dumb. An adaptive corridor perceives the real queue and re-plans every cycle — a loop, at a junction, all day.

Cities running these report meaningfully shorter trip times on managed corridors — the loop, paying rent.

Act V · The synthesis

Every real agent: soft core, hard shell

Hard shell · invalidate · authenticate · route · rate-limit
Soft coremodel reasons, plans, drafts, picks a tool
Hard shell · every actiontype-check args · permission-check · dry-run the reversible ones
Hard shell · outverify vs criteria · log · gate · (human sign-off on the irreversible)

The model proposes. Plain, tested code disposes. It can't hallucinate its way past the shell.

Act V · Build it well

Six rules that keep an agent trustworthy

🔹Simple

Smallest loop that helps

One sensor, one tool, one nudge. Add only when that plainly fails.

🪟Visible

Show the "why now"

Can't watch it think → can't trust it, and you'd be right.

🚧Bounded

Hard rails on anything costly

Caps & allow-lists in code, not prompt text.

↩️Reversible

Every action has an undo

Mute, snooze, cancel — in one tap.

🧭Consensual

You're the principal

Optimizes your stated goal. Stops when you say stop.

💛Kind

Never nag

A guilt-trip is a failed nudge. Be useful and warm, or do nothing.
